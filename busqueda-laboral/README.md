# Relevamiento: oportunidades para fotógrafa y maquilladora social

Zona Norte GBA (Vicente López, San Isidro, San Fernando, Tigre, Escobar, Pilar)
y zonas de CABA lindantes con Zona Norte (Belgrano, Núñez, Palermo).

Relevado el 22/08/2026. **76 contactos y fuentes.**

## Archivos

- `Contactos-fotografia-maquillaje-ZonaNorte.pdf` — versión para leer e imprimir (6 páginas, links clicables).
- `Contactos-fotografia-maquillaje-ZonaNorte.xlsx` — versión para filtrar y trabajar (5 hojas, con autofiltro).

## Contenido

| Bloque | Qué trae |
|---|---|
| 1. Avisos concretos (16) | Búsquedas puntuales identificadas, con nombre de aviso, detalle y link |
| 2. Oficinas de Empleo (7) | Portales municipales de Zona Norte **con teléfono y mail directos** |
| 3. Búsquedas guardadas (38) | URLs ya filtradas por puesto y zona, para revisar cada semana |
| 4. Canales y directorios (15) | Dónde los avisos sí publican WhatsApp o mail directo |

## Regenerar

Los datos están en `datos.py`. Para actualizar la lista, editar ese archivo y correr:

```
pip install openpyxl reportlab
python3 generar.py
```
